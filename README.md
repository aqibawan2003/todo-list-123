# Todo List App

A beautiful, production-quality todo list app built with React, Vite, and Tailwind CSS. Features include task management, dark mode, and localStorage persistence.

## Live Demo

https://list-spark.vercel.app/

## Features

- Add, edit, complete, and delete tasks
- Persistent task storage using localStorage
- Dark mode support
- Clean, responsive UI built with Tailwind CSS
- Fast development workflow using Vite

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- HTML
- CSS

## Language Composition

- JavaScript: 96.5%
- HTML: 2.5%
- CSS: 1%

## Project Description

This project is a modern todo list application designed for daily task management with a polished user experience and reliable browser-side persistence.
